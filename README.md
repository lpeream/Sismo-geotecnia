# Proyecto de sismo-geotecnia

El proyecto se organiza por entregas:

- [Entrega_01](./Entrega_01/README.md): primera entrega con el informe, el codigo, los datos, las figuras, los recursos y las instrucciones para reproducir el analisis.
- [Entrega_02](./Entrega_02/README.md): segunda entrega con plantilla LaTeX, PDF y recursos propios.

Para trabajar con la primera entrega, entra en `Entrega_01` y sigue su README. La configuracion Git permanece en la raiz del repositorio. Los entornos virtuales y archivos temporales de compilacion son locales o reproducibles, por lo que no forman parte de las entregas.

El repositorio Git anidado que estaba en la raíz se conservó dentro de `Entrega_01/informe_fuente/`, sin alterar su estado de fusión. Los informes preparados para cada entrega están en sus respectivas carpetas `informe/`.
