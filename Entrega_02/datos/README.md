# Datos CSV para la Entrega 2

Se copiaron los 63 archivos CSV que están en `Entrega_01/datos/`, manteniendo
las mismas rutas relativas y subcarpetas (`datos depurados`, `datos
estadistica`, `datos originales` y `datos sismo`). Así, la Entrega 2 conserva
los datos tabulares utilizados para producir los análisis, tablas y figuras de
la Entrega 1, sin depender de rutas a la carpeta de la entrega anterior.

Las copias conservan los nombres y contenidos de sus archivos de origen. Se
incluyen catálogos sísmicos originales y depurados, resúmenes estadísticos,
archivos de auditoría, espectros y registros utilizados en la selección y
ajuste de acelerogramas.
